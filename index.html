Backup Data BUMDes

Unduh salinan data dari Supabase ke komputer sebagai file JSON. Simpan file ini di tempat aman (misalnya komputer dan penyimpanan cloud pribadi). Lakukan backup secara rutin, terutama setelah banyak transaksi atau sebelum perubahan besar.

Isi backup
Master Barang · Stok · Barang Masuk · Penjualan · Pengeluaran · Kas
Format file
JSON (.json)
Menyimpan data lengkap beserta nama kolomnya.
Catatan penting:
• File backup ini adalah salinan data, bukan file aplikasi HTML.
• Jangan menyimpan satu-satunya salinan backup di komputer yang sama dengan aplikasi.
• Fitur ini mengunduh data; pemulihan dari file backup perlu dilakukan dengan prosedur restore yang sesuai agar transaksi kas dan stok tidak terduplikasi.
